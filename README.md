# Siwat Tonok Portfolio

เว็บไซต์ Portfolio ของนายศิวัสว์ โตนอก ออกแบบสำหรับเผยแพร่ด้วย GitHub Pages

## เว็บไซต์

- Portfolio: https://arty2525.github.io/portfolio/
- คลังเกียรติบัตร: https://arty2525.github.io/portfolio/certificates.html

เว็บไซต์เผยแพร่ด้วย GitHub Pages จาก Branch `main` และโฟลเดอร์ `/(root)`

## เนื้อหาปัจจุบัน

- ประวัติและความเชี่ยวชาญ
- รายวิชาที่สอน
- พื้นที่แสดงโครงงานและนวัตกรรม
- คลังเกียรติบัตร 109 รายการ พร้อมภาพย่อและระบบขยายภาพ

## การเพิ่มผลงานภายหลัง

- เพิ่มรูปผลงานในโฟลเดอร์ `assets`
- แก้ไขส่วน `PORTFOLIO` ใน `index.html`
- Commit การเปลี่ยนแปลง แล้ว GitHub Pages จะอัปเดตเว็บไซต์ให้อัตโนมัติ

## หมายเหตุด้านความเป็นส่วนตัว

เว็บไซต์รุ่นนี้แสดงเพียงอำเภอและจังหวัด ไม่แสดงบ้านเลขที่หรือที่อยู่เต็ม เพราะเว็บไซต์ GitHub Pages เข้าถึงได้แบบสาธารณะ
